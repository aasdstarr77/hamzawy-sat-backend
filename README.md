# حمزاوي سات — Backend v0.2

هذه النسخة تطور الـBackend السابق وتضيف:

- تسجيل حساب عميل أو فني.
- تشفير كلمات المرور باستخدام bcrypt.
- تسجيل دخول وإصدار JWT.
- حماية الـAPI حسب الدور.
- لوحة بيانات للأدمن.
- اعتماد الفنيين.
- إدارة الطلبات وتسعيرها.
- خصم ذري وآمن عند فتح الطلب.
- رصيد الفني.
- رفع إيصال الشحن كصورة فعلية (JPG/PNG/WEBP حتى 5MB).
- منع تكرار رقم العملية عند وجوده.
- مراجعة الشحنات بالموافقة أو الرفض.
- تعديل بيانات محفظة الأدمن.
- سجل معاملات الرصيد.

## التشغيل
Node.js 20+
```bash
npm install
JWT_SECRET="ضع-مفتاح-سري-قوي" npm start
```

> لا تستخدم المفتاح الافتراضي في الإنتاج.

## مهم قبل الإنتاج
- PostgreSQL أو MySQL بدل SQLite عند التوسع.
- HTTPS.
- تخزين صور الإيصالات في Object Storage مع صلاحيات خاصة، وليس مجلدًا عامًا.
- حماية Admin أقوى (MFA/2FA).
- rate limiting وvalidation وaudit logs.
- نظام إشعارات Push.
- حذف/تنظيف الإيصالات حسب سياسة الاحتفاظ.
